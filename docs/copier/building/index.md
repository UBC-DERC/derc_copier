# Building Better Code

We get caught up in whether our code is "Good Enough". Rest assured, your code is always good enough to share. If we don't share our code we'll never be able to improve it, because we get better by sharing, and learning from one another.

Nick Barnes wrote exactly this back in 2010 in Nature: "[Publish your code: It's good enough](https://www.nature.com/articles/467753a)".

But ,there are some quick, and some more complicated things we can do to make our code more readable, for us and for others.
