# DERC GitHub Best Practices

This site does two things:

- It documents the **DERC project template** &mdash; a [`copier`](https://copier.readthedocs.io/)
  template that scaffolds a well-structured R or Python project for you, and keeps
  it linked to our latest recommendations so you can update it over time.
- It explains the **best practices** behind that template &mdash; the *why* as well
  as the *how* &mdash; so you can make good decisions about your own research
  software.

It is intended to act as a set of best-practice documents to help users understand
what to do, and why to do it.

## Where to start

- **New here?** Go to [**Using the DERC Template**](copier/using/index.md) to
  install the tools and generate your first project in three short steps.
- **Want the reasoning?** Browse [**Best Practices**](copier/index.md) to learn
  about attribution, community, and staying organized.
